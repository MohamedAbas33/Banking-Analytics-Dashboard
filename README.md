# 📊 Banking Analytics Dashboard

## 📌 Project Overview
This project is an interactive Power BI dashboard designed to analyze banking data and provide business insights about customers, transactions, loans, and support calls.

- Customers
- Transactions

- Support Calls
- Loan Tracking

- Loan Tracking
- Data Model
